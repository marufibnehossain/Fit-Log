# FitLog

## Description

FitLog is a workout library application built with Next.js that helps users explore exercises, view workout details, create a personal workout plan, and save workouts for later.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- React Icons
- React Toastify

## Features

- Browse workouts from an external API
- View detailed information about each workout
- Add workouts to today's plan
- Save workouts for later
- Remove workouts from plans
- Mark workouts as completed
- Sort workouts by duration, calories, and rating
- Responsive design for mobile, tablet, and desktop

npm install
